# A+ Focus Lab

A static, no-build practice site for **CompTIA A+ V15 Core 1 (220-1201)** and **Core 2 (220-1202)**.

Built for short, active study sessions rather than long lecture blocks. The question bank is original and based on the published A+ V15 domains/objectives; it does **not** contain copied live exam questions or third-party practice questions.

## Features

- 459 generated/original practice-question variants across both current A+ exams
- Core 1, Core 2, and mixed review modes
- Quick 10, Focused 20, Deep 50, and Full 90 sessions
- Official domain-weighted selection for Core 1/Core 2 all-domain sessions
- Study mode with immediate explanations
- Exam mode with feedback at the end
- Optional timer (90 questions = 90 minutes; shorter sessions scale proportionally)
- Flag questions during a session
- Domain-by-domain result breakdown
- Local browser progress tracking
- Weak-domain-biased practice
- Resume unfinished sessions
- Dark mode
- No backend, build system, framework, account, or analytics

## GitHub Pages

1. Make the repository public if your GitHub plan requires public repositories for Pages.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

No build command is required.
